## 3. Что сделано (по темам)

**Скрипт и подключение**
- Один `pnl.gs` для всех клиентов: ключ = ID таблицы, править под клиента ничего не нужно.
- Справочник в 3 колонки: A Тип (Доход / Переменные / Постоянные / Фонд / Не учитывать / Прочее), B Отдел, C Статья. Строка заголовков ищется в первых 6 строках.
- Если направление не совпало ни с одной строкой, скрипт пишет, какие направления есть в базе.
- Фонды определяются по листу «ДДС БОТ ФОНДЫ» (флаг `fund`), а не только по слову «фонд» в счёте.

**Кабинет клиента: Мой кабинет**
- Месяц с одними расходами тоже показывается (раньше нужен был доход).
- Прибыль в минусе: плитка красная, заголовок «Убыток», без процента сравнения.
- Расходы видны и без выручки.

**Ключевые метрики** (одинаковые у всех клиентов)
- ⚖️ Точка безубыточности: цветная кнопка-плашка (синяя / зелёная, если пройдена), сумма + количество товаров или заказов, по нажатию открывается расчёт.
- Дивиденды, возвраты, налоги, ФОТ: % от выручки и сумма, по названию статьи. ФОТ по нажатию раскрывает список статей.
- Подсказки «откуда цифры» скрыты. «Кубики» → «товары».
- Кнопка «📥 Внести данные от ОП» (видит только владелец).

**Товары 📦**
- Листы: «Товары Поставки» = приход, «Товары Реализации» = расход, «Товары Инвентаризация» = факт.
- В каждой колонке шт и ₽. Суммы по средней цене закупки, «продано на» = сумма продажи. Строка «Итого».

**ДДС**
- Вводный остаток по выписке за любой месяц, «⧉ Взять конец прошлого месяца», «↩ считать автоматически», подсказка о расхождении с расчётом.
- Фонды: владелец вводит остатки на начало по каждому фонду (видит только владелец).

**Вид кабинета**
- 📦 Товары (по умолчанию, как было) или 🛠 Услуги: переключатель в предпросмотре кабинета. Услуги: без вкладки «Товары» и «Продано товаров», точка безубыточности в заказах, блок «Клиенты и заказы».

**Мини-CRM для клиентов на услугах** (вкладки 🏠 Главная · ₽ Финансы · 👥 Клиенты)
- Главная: выручка за месяц, проектов в работе, сколько клиентов не оплатили (и сумма долга), чистая прибыль / убыток.
- Финансы: доходы и расходы за месяц; доход можно привязать к проекту (это оплата), расход — к статье.
- Клиенты: база клиентов (имя, телефон, заметка) и проекты (клиент, услуга, стоимость, в работе / готов, оплачено / долг).
- Данные: `workspaces/{ws}/clients/{cid}/crm` (kind: client / project / move). Пишет сам клиент, владелец видит и может править.

**Доступы и скрытие**
- Скрыть месяц от клиента: кнопка «👁 Скрыть» рядом с месяцем. У клиента месяца нет нигде; в аналитике подписано «нет данных», слова «скрыт» клиент не видит.
- «Данные от ОП» клиент видит только для просмотра. Владелец открывает или закрывает ему правку «Данных от ОП» и «Планирования» одной кнопкой («🔒 / 🔓»).

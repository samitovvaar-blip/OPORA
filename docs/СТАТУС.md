## Если меняется `firestore.rules` или `apps-script/pnl.gs`
Обновить вручную и записать сюда дату:
- **Правила:** Firebase → Firestore → Rules → вставить файл целиком → «Опубликовать».
- **Скрипт:** Apps Script → вставить `pnl.gs` → Развёртывание → Управление → ✏️ → «Новая версия».

# Логика кабинетов клиента: откуда берутся данные и куда уходят

Есть **два вида кабинета**. Вид выбирается в мастере «Новый клиент», менять может только владелец (⚙ проекта → «Вид кабинета»).

| | 📦 Товарный бизнес | 🛠 Услуги |
|---|---|---|
| Главный источник цифр | **Google-таблица клиента** | **сам кабинет** (клиент вносит данные) |
| Направление данных | таблица → кабинет | кабинет → таблица |
| Кто вносит данные | бухгалтер или бот в таблицу | клиент или бухгалтер в кабинете |
| Связь с таблицей | скрипт `pnl.gs`, чтение (doGet) | скрипт `pnl.gs`, запись (doPost) |

---

## 📦 Кабинет «Товарный бизнес»

### Как устроено

```
Google-таблица  ──(скрипт pnl.gs, раз в 10 мин или по 🌀)──▶  кабинет (только показывает)
```

Кабинет **ничего не пишет в таблицу**. Всё, что видит клиент, посчитано из таблицы. Несколько вещей вносятся в самом кабинете, они хранятся в Firebase и в таблицу не попадают.

### 1. Что вносится В ТАБЛИЦУ

| Лист | Обязателен? | Что вносить | Куда идёт в кабинете |
|---|---|---|---|
| **ДДС БОТ ОСНОВНЫЕ** | ✅ да | все операции по счетам: Направление · Процессы · Статьи · Сумма · Приход/Расход · Дата операции · Дата для отчёта · Счёт | ОПиУ, ДДС, аналитика, плитки, ключевые метрики, структура расходов, советы Нейлы |
| **ДДС БОТ ФОНДЫ** | ✅ лист должен быть, может быть пустым | операции фондов | таблица «Фонды» в ДДС; траты из фондов в ОПиУ |
| **Справочник-общее** | желательно | A — Тип (Доход / Переменные / Постоянные / Фонд / Не учитывать / Прочее), B — Отдел, C — Статья. Справа блок «Группа товаров / номенклатура товара» | раскладка ОПиУ по типам и отделам, структура расходов, группы товаров |
| **БАЛАНСЫ СЕЙЧАС** | желательно | остатки по счетам и фондам на дату ввода | «Остаток на начало» в ДДС, фонды |
| «Товар… **Поставк**…» | для товарного учёта | Номенклатура · Кол-во · Сумма · Дата для отчёта | Товары: **приход** (шт и ₽ закупки) |
| «Товар… **Реализац**…» | для товарного учёта | то же | Товары: **расход** (шт, ₽ по себестоимости, «продано на») |
| «…**Инвентаризац**…» | для товарного учёта | Номенклатура · Кол-во · Сумма · **Дата для отчёта = последний день месяца** | Товары: **факт** и расхождение. Следующий месяц стартует от факта |

**Правила по датам:**
- **ОПиУ** считается по **«Дате для отчёта»**, **ДДС** по **«Дате операции»**.
- Инвентаризацию на конец месяца датируй **последним днём этого месяца** (31.10, а не 05.11), иначе она уйдёт в следующий месяц.

**Скрипт не читает:** ОТЧЁТ ОПИУ, сводные, проверки, платёжный календарь в таблице, ДДС НАЛИЧКА, ДДС Субсчета, планы встреч и любые рабочие листы.

⚠️ Не называй рабочие листы просто «ТОВАРЫ» или «Товарный учёт». Если нет листов поставок и реализаций, скрипт попробует прочитать такой лист как движение товара. Если он на это не похож, скрипт его пропустит.

### 2. Что вносится В КАБИНЕТЕ (хранится в Firebase, в таблицу не уходит)

| Что | Где | Кто | Зачем |
|---|---|---|---|
| Выручка ОП, предоплаты, кол-во товаров, заказы, новые клиенты, план продаж | 📥 Данные от ОП | ты (клиент, если открыла доступ) | выручка в ОПиУ, средний чек, CAC, точка безубыточности в штуках, цель месяца |
| План по отделам, фокус месяца, платёжный календарь | 🎯 Планирование | ты (клиент, если открыла доступ) | план/факт, кассовые разрывы |
| Статусы задач, созвоны | 🛠 Ход работы | ты и сотрудники | клиент видит, что сделано |
| Вводный остаток по выписке, остатки фондов на начало | Отчётность → ДДС | ты | остаток на начало месяца |
| Факт инвентаризации (если нет в таблице) | Отчётность → Товары | ты | факт и расхождения |
| «✓ Сдано», скрытие месяца | ⚙ проекта / вверху кабинета | ты | заморозка цифр, что видит клиент |

### 3. Обновление

- Кабинет хранит ответ скрипта **10 минут**. Кнопка **🌀** берёт свежие данные сразу.
- Сданные месяцы **заморожены** (снимок). Правки в таблице их не меняют, пока не снимешь «Сдано».

## 🛠 Кабинет «Услуги»

### Как устроено

```
кабинет (клиент вносит)  ──(сразу, через 1–2 сек)──▶  Google-таблица (листы «ПРИЛОЖЕНИЕ …»)
```

Здесь **всё наоборот**: данные живут в кабинете (Firebase), а таблица — их **копия** для тебя: сводные, формулы, отчёты.

### 1. Что вносится В КАБИНЕТЕ

| Вкладка | Что вносится | Что считается |
|---|---|---|
| **📦 Продукты** | услуги и цены | сумма проекта подставляется сама |
| **👥 Клиенты → База лидов** | лиды: имя, компания, контакт, откуда, статус, заметки, комментарии | свод по статусам и источникам, конверсия, LTV |
| **👥 Клиенты → Проекты** | клиент, продукты, сумма в месяц, число оплаты. Внутри проекта: **оплаты** («✓ Оплатили», «+ Внести оплату») и **расходы проекта** (в т.ч. ежемесячные) | доходы, расходы, прибыль, маржа проекта, долг, «не оплатили» |
| **👷 Сотрудники** | имя, проекты, способ оплаты (фикса общая / фикса на свои проекты / % от проектов) | ЗП в расходы проекта или общие, план расходов |
| **₽ Финансы** | **общие** доходы и расходы (аренда, сервисы), ежемесячные шаблоны («Провести») | план/факт, структура расходов, остатки по счетам, рентабельность |

**Правило:** доходы и расходы **по проекту** вносятся только **внутри проекта**, **общие** только в **Финансах**.

### 2. Что уходит В ТАБЛИЦУ (автоматически)

Как только что-то добавили, изменили или удалили, через 1–2 секунды скрипт **переписывает** три листа:

| Лист в таблице | Колонки |
|---|---|
| **ПРИЛОЖЕНИЕ ФИНАНСЫ** | Дата · Месяц · Приход/Расход · Сумма · Счёт · Статья · Проект · Клиент · Комментарий |
| **ПРИЛОЖЕНИЕ ПРОЕКТЫ** | Начало · Проект · Продукт · Клиент · Стоимость · Оплачено · Долг · Статус · Срок · Дата оплаты · Расходы · Прибыль · Маржа |
| **ПРИЛОЖЕНИЕ КЛИЕНТЫ** | Клиент · Компания · Телефон · Откуда · Заметка · В базе с · Статус |

⚠️ Эти листы **перезаписываются целиком**. Руками в них не пиши, свои формулы и отчёты делай на **других листах** со ссылкой на «ПРИЛОЖЕНИЕ …».

Привязка таблицы: вкладка **«Нейла» → Google-таблица** (ссылка на таблицу + ссылка …/exec скрипта).

### 3. Что из таблицы берётся в кабинет

**Ничего.** Кабинет «Услуги» таблицу не читает. Если поправить цифры в таблице, в кабинете они не изменятся. Правки делай в кабинете.

## 🔁 Общий скрипт `pnl.gs`

Один и тот же файл для всех клиентов. Вставляется в каждую таблицу: Расширения → Apps Script → Развёртывание «Веб-приложение», доступ «Все».

| Функция | Для какого кабинета | Что делает |
|---|---|---|
| `doGet` | 📦 Товары | читает листы ДДС, справочник, балансы, товары и отдаёт цифры кабинету |
| `doPost` | 🛠 Услуги | принимает данные из кабинета и пишет листы «ПРИЛОЖЕНИЕ …» |

После каждого обновления скрипта: **Управление развертываниями → ✏️ → «Новая версия»**.

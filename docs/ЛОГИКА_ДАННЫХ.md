# Откуда кабинет клиента берёт цифры

Таблица: **«ФИНАНСЫ ОПиУ YourBox / Арина+Аслан»**.
Цифры из таблицы собирает скрипт `apps-script/pnl.gs` (Расширения → Apps Script).
Готовый результат он запоминает на 10 минут. Кнопка ↻ в кабинете пересчитывает сразу.

---

## 1. Какие листы читает скрипт. Их НЕЛЬЗЯ удалять и переименовывать

| Лист (имя должно совпадать точь-в-точь) | Что из него берётся | Куда идёт в кабинете |
|---|---|---|
| **ДДС БОТ ОСНОВНЫЕ** | все операции основных счетов | ОПиУ, ДДС (приход, расход, прочее), Аналитика, ключевые метрики, график по месяцам |
| **ДДС БОТ ФОНДЫ** | операции фондов: пополнения и траты | траты из фондов → ОПиУ (по своим отделам); таблица «🏦 Фонды» в ДДС |
| **Справочник-общее** | колонка A — группа (процесс), колонка B — статья | правит процесс у статьи: статья попадает в тот отдел, который указан в справочнике |
| **БАЛАНСЫ СЕЙЧАС** | остатки по счетам и фондам на дату ввода (колонка A), сверка (B, C, F), остаток сейчас (D), счёт (E) | «Остаток на начало / на конец месяца» в ДДС, начальные остатки фондов, остаток на начало в платёжном календаре |

> ⚠️ Если переименовать или удалить любой из этих 4 листов, отчёт в кабинете перестанет загружаться и покажет ошибку «Лист не найден».

## 2. Какие колонки нужны на листах «ДДС БОТ ОСНОВНЫЕ» и «ДДС БОТ ФОНДЫ»

Скрипт ищет колонки **по названию в первой строке** (по началу слова, регистр не важен).
Порядок колонок значения не имеет.

| Заголовок начинается с… | Обязательно | Зачем |
|---|---|---|
| **Направление** | ✅ | берутся только строки с направлением **«Кубики»**. Если колонок «Направление» несколько, проверяются все |
| **Статьи** | ✅ | статья операции (строки в отчётах) |
| **Сумма** | ✅ | сумма операции |
| **Процесс** | желательно | отдел и процесс (1.x … 6.x, «Доходы», «** ДЛЯ ДДС», «Субсчета») |
| в названии есть **«приход»** | желательно | приход это или расход. Если колонки нет, берётся знак суммы |
| **Дата для отчёта** | желательно | по ней месяц попадает в **ОПиУ** |
| **Дата операции** | желательно | по ней месяц попадает в **ДДС** |
| **Счёт** | желательно | счёт операции (для фондов и остатков) |

> ⚠️ Если переименовать заголовки «Направление», «Статьи» или «Сумма», появится ошибка «Не нашёл колонки…».

## 3. Правила, по которым строки раскладываются

**ОПиУ (по «Дате для отчёта»)**
- **Выручка** — только процесс **«Доходы»**. Если в «📥 Данные от ОП» внесена «Выручка ОП», в отчёте выручкой становится она, а банк показывается строкой «Поступления по банку (для сверки)».
- **Расходы** — процессы **1.x–5.x**: 1–3 переменные, 4–5 постоянные.
- **6.x Фондирование** — показывается **под** чистой прибылью, в расходы не входит.
- **Не попадают в ОПиУ**: процессы «** …» (ДЛЯ ДДС), «Субсчета», статьи «Между счетами» и «внутренние переводы». Процесс «Расходы» (вывод на личный счёт) тоже не попадает.
- **Налоги** (статья со словом «налог», кроме фондов) — всегда в **5. Финансовый отдел**.
- **Выручка доставка СДЭК** — в том же процессе, что «Выручка почта».

**ДДС (по «Дате операции»)**
- Отчёт строится **только по листу «ДДС БОТ ОСНОВНЫЕ»**.
- **Приход** — процесс «Доходы».
- **Расход** — все остальные процессы.
- **Прочее** (отдельная таблица внизу): «** ДЛЯ ДДС», «Не выяснено», «Субсчета», «Между счетами», фонды и 6.x.
- **Остаток на начало** = остатки из «БАЛАНСЫ СЕЙЧАС» (блок «1. Балансы на счетах») + все движения после даты ввода остатков.

**Фонды (таблица в ДДС)**
- Берутся счета из блока «Балансы на Фондах» листа «БАЛАНСЫ СЕЙЧАС» и их операции с листа «ДДС БОТ ФОНДЫ».
- Схема: на начало + пополнено − потрачено = на конец. Минус подсвечивается красным, это значит ошибка в базе.

**Опечатки в датах.** Если год «Даты операции» и «Даты для отчёта» различается, скрипт выдаёт список таких строк, чтобы их можно было найти.

## 4. Какие листы скрипт НЕ читает

Ни один из этих листов не влияет на цифры в кабинете:

- ОТЧЁТ ОПИУ
- Статистика по дням
- ПЛАТЁЖНЫЙ КАЛЕНДАРЬ
- Проверки / Сводные таблицы
- ДДС Субсчета
- ДДС НАЛИЧКА / Данные
- «сентябрь инфа из чата» и другие рабочие листы

> ⚠️ Прежде чем удалять, проверь:
> 1. **Твои формулы.** Не ссылаются ли на этот лист формулы на других листах. Например, колонка D «остаток сейчас» на «БАЛАНСЫ СЕЙЧАС» считается формулой по «ДДС БОТ ОСНОВНЫЕ». Если удалить лист, на который она ссылается, сломается остаток.
> 2. **Бот.** Не пишет ли телеграм-бот операции в этот лист.
> 3. **Наличка.** Операции с листа «ДДС НАЛИЧКА» в кабинет **не попадают**. Если наличка должна быть в отчётах, её нужно вносить в «ДДС БОТ ОСНОВНЫЕ» или подключить этот лист к скрипту.

## 5. Что вносится НЕ в таблицу, а в кабинете (хранится в Firebase)

| Данные | Где вносить | Куда идёт |
|---|---|---|
| Выручка ОП, предоплаты, кубики, клиенты, заказы, план продаж | 📥 Данные от ОП | выручка в ОПиУ, проверка предоплат, себестоимость на единицу, средний чек, CAC, цель месяца |
| Плановые платежи | 🎯 Планирование → платёжный календарь | план расходов, кассовые разрывы |
| Статусы, дата загрузки, итоги созвонов | 🛠 Ход работы | видит клиент |
| «✓ Сдано» по месяцу | Проект → ⚙ Кабинет клиента | статус месяца, кнопка PDF, **заморозка цифр** |

---

## 6. Заморозка сданных месяцев 🧊

- Когда ставишь «✓ Сдано», кабинет **сохраняет снимок** всех цифр этого месяца: ОПиУ и ДДС.
- После этого месяц **показывается из снимка**. Правки или поломки в таблице его больше не меняют.
- Если снять «Сдано», снимок удаляется, и месяц снова берётся из таблицы. Чтобы исправить цифры сданного месяца, сними «Сдано», поправь таблицу и поставь «Сдано» снова.
